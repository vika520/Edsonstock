# EdsonStock · A股市场结构工作台

16 个栏目、一个 HTML 文件、零外部依赖。打开即看当天与历史的市场结构，
每个指标都标明它来自真实公开数据、量价代理，还是确认拿不到。

## 它解决什么问题

大多数行情工具只告诉你「今天发生了什么」，很少说清楚三件事：
1. 这个数字是真实成交/披露数据，还是用量价推算的代理？
2. 历史序列是真回补的，还是从上线那天才开始累积？
3. 这个「有效信号」在剔除未来函数和样本重叠后还剩多少？

本工作台把这三件事作为一等公民，写进每一个栏目、复盘和回测报告。

## 核心特性

- **单文件离线**：HTML + CSS + Canvas + 内嵌 JSON，双击即开，不联网、不装包、无 CDN。
- **全公开数据源**：新浪 / 腾讯 / 东财 / 中金所 / 同花顺，不依赖任何付费接口或 MCP 授权。
- **口径分级标注**：真实、代理、不可得三类在页面、复盘、数据文件三处一致披露。
- **严格因果意识**：每个「信号有效」的结论都做双口径检验——含未来函数的描述性口径，和只用当日及之前数据的严格因果口径。
- **长历史可回补就补**：行业 PE 中位数 250 日、涨停/连板/晋级率 250 日、外部环境 460 日，均按日入库。
- **拿不到就明说**：ETF 日度官方份额、TMT 同口径占比历史、炸板率/跌停家数历史，逐条写明原因与替代方案，绝不插值伪造。
- **盘后自动更新**：交易日 16:00 自动生成当日复盘、重建工作台、部署静态站点并同步仓库。

## 快速开始

```bash
# 直接打开
open A股市场结构工作台.html

# 或本地起服务
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

数据脚本位于 `wolf-cycle/`，全部使用标准库 + `urllib`/`curl`：

```bash
cd wolf-cycle
python daily_update.py              # 完整盘后链路（非交易日自动跳过）
python main.py                      # 仅本地重建工作台
python fetch_extras.py              # 6 类补充数据
python backfill_history.py --incremental   # 长历史增量回补
```

## 数据口径（三档）

| 档位 | 例子 | 处理方式 |
| --- | --- | --- |
| 真实公开数据 | 两融余额、中金所行情与会员排名、指数/ETF 日线、解禁与龙虎榜 | 原样展示，标明披露时滞（两融 T+1、中金所收盘后） |
| 量价代理 | 「净流入」、方向代理、TMT 成交占比、拥挤度综合分 | 页面显著标注「代理，非真实资金流」 |
| 确认不可得 | ETF 日度官方份额、期权 IV/skew、Level-2 逐笔、分析师一致预期修正、北向日度净买入 | 写明原因与替代方案，不伪造、不插值 |

特别说明：全市场涨跌家数自 2026-11-14 起改用新浪全 A 快照统计；北向资金日度净买入自 2024-08-19 起不再披露，因此不构建该因子。

## 已经做过的因果检验（结论均为不显著）

| 信号 | 描述性口径 | 严格因果口径 | 结论 |
| --- | --- | --- | --- |
| 双冰点后次日上涨 | 55.6% | 基准 52.5%，单尾 p=0.45 | 广度均值回归强，但指数价格传导弱 |
| 威科夫 Phase C 兑现 | 页面标注成立 | 近三年 12 次信号，兑现率 25%，p=0.256 | 结构识别可作观察，不可当买点 |
| ERP ≥ 90 分位后上涨 | 全样本阈值下 120 日 70.6%、250 日 79.4%（p<0.05） | 扩展窗口 / 1250 日滚动两种无未来函数口径均不显著 | 漂亮胜率来自「用全样本定义低估线」的未来函数 |
| ERP ≥ 75 分位后上涨 | 重叠采样下 120 日 67.4% | 按区间首次进入去重后 56.5%，不显著；中位数结论对样本起点敏感 | 中长期有倾向但不稳健，高度依赖 2008/2009 |

详见 `ERP_90分位事件研究.html` 与 `ERP_75分位反弹研究.html`。

## 技术结构

```
.
├── A股市场结构工作台.html      # 16 栏单文件成品（内嵌数据与前两个页面）
├── A股狼波周期指数走势图.html
├── A股双冰点情绪指标.html
├── 每日复盘_<date>.html        # 可分享的单篇复盘
├── ERP_90分位事件研究.html     # 因果检验报告
├── ERP_75分位反弹研究.html
└── wolf-cycle/
    ├── fetch_*.py              # 各数据源取数
    ├── backfill_history.py     # 长历史回补
    ├── build_*.py              # HTML 构建
    ├── wb_*.js                 # 栏目视图
    ├── views.json              # 栏目顺序、分组、固定编号的唯一配置源
    └── data/                   # 聚合后的 JSON 数据源
```

栏目顺序、分组标题与固定编号由 `views.json` 单点驱动；`build_workbench.py` 会校验分组与编号的连续性，配置写错直接构建失败。

## 免责

本项目所有内容均为数据统计与可视化，**不构成投资建议**。市场有风险，决策请自行判断。
日频 PE 由月末官方锚点重构，不是官方发布的日频数据；ERP 衡量股债相对性价比，不是择时信号。
所有阈值与判读规则为预设固定值，未做参数寻优；若未来调参贴合历史曲线，即构成过拟合。
